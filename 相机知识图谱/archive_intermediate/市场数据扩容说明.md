## 导入方式

如果 Python 连接 Neo4j 报密码错误，就在 Neo4j Desktop 的 Query 页面执行：

```text
F:\dongqiyan\知识图谱期末大作业\相机知识图谱\market_import.cypher
```

我已把该脚本复制到剪贴板，可以直接在 Query 输入框 `Ctrl+V` 后运行。

导入后验收：

```cypher
MATCH (n:Entity) RETURN count(n) AS 节点数;
```

```cypher
MATCH (:Entity)-[r]->(:Entity) RETURN count(r) AS 关系数;
```

## 抓取脚本

运行：

```powershell
cd F:\dongqiyan\知识图谱期末大作业\相机知识图谱
py market_crawler.py
```

输出：

```text
market_crawl_raw.csv
```

说明：京东、淘宝搜索页都有动态渲染和反爬机制，脚本用于快速抓取公开 HTML 中能读到的标题、价格和链接；课程作业更推荐使用 `market_*` CSV 作为稳定展示数据。

## 对话系统增强

`camera_advisor_app.py` 已支持：

- 新增市场机型识别，例如 `ZV-E10 II`、`X-S20`、`EOS R8`、`Z 50II`。
- 识别不同语境：新手、小白、热销、主流、性价比、旅行、拍娃、人像、直播、Vlog、已有镜头。
- 推荐分加入 `marketHotScore` 市场热度。
- 页面展示市场热度、市场备注、数据来源。
- 可选大模型解析：设置 `OPENAI_API_KEY` 后，规则识别不到的模糊问题会尝试用大模型解析为意图 JSON。
