# Neo4j Desktop 导入与导购应用说明

## 一、已准备的数据

本文件夹已有以下数据：

- `node.csv`：品牌、相机型号、类别、镜头、组件、性能指标等基础节点。
- `edges.csv`：生产、类别、兼容、组件、指标、换代等基础关系。
- `camera_extra_nodes.csv`：新增用途场景、预算档位、推荐理由节点。
- `camera_extra_edges.csv`：新增导购关系，例如“某型号适合视频创作”“某型号推荐理由是轻便机身”。
- `camera_graph_import.cypher`：Neo4j 一键建图脚本。
- `导购查询示例.cypher`：后续展示和答辩可用的查询语句。

## 二、在 Neo4j Desktop 中创建图谱

1. 打开 Neo4j Desktop，新建或选择一个 Project。
2. 添加一个本地 DBMS，建议命名为 `camera-kg`。
3. 启动数据库，打开 Neo4j Browser。
4. 在 Browser 中执行 `camera_graph_import.cypher` 的全部内容。
5. 执行以下语句查看图谱：

```cypher
MATCH p=()-[]->()
RETURN p
LIMIT 120;
```

## 三、图谱实体与关系

实体类型：

- `Brand`：索尼、佳能、尼康、富士。
- `CameraModel`：相机型号。
- `CameraCategory`：全画幅微单、APS-C画幅微单、中画幅微单。
- `Lens`：镜头。
- `Component`：处理器、传感器等组件。
- `ParameterIndex`：视频规格、连拍速度等性能指标。
- `UseCase`：旅行随拍、人像摄影、视频创作、体育生态摄影、入门学习、商业专业拍摄。
- `PriceBand`：入门预算、中端预算、高端预算、专业预算。
- `Reason`：轻便、全画幅、视频规格、高速连拍、镜头生态、预算友好等推荐理由。

关系类型：

- `PRODUCED_BY`
- `BELONGS_TO_CATEGORY`
- `COMPATIBLE_WITH`
- `EQUIPPED_WITH`
- `ACHIEVES_INDEX`
- `SUCCESSOR_OF`
- `SUITABLE_FOR`
- `IN_PRICE_BAND`
- `HAS_REASON`

## 四、导购应用思路

导购系统可以把用户输入转化为图谱查询条件：

| 用户问题 | 图谱条件 |
|---|---|
| 预算 17000 以内 | `m.price <= 17000` |
| 想拍视频 | 连接 `UseCase{name:'视频创作'}` |
| 想拍人像 | 连接 `UseCase{name:'人像摄影'}` |
| 偏好索尼 | 连接 `Brand{name:'索尼'}` |
| 想要全画幅 | 连接 `CameraCategory{name:'全画幅微单'}` |
| 已有某品牌镜头 | 通过 `COMPATIBLE_WITH` 查询兼容机身 |

一个简单推荐分可以由三部分组成：

```text
推荐分 = 用途匹配分 + 预算匹配分 + 品牌偏好分 + 性能指标加分 - 超预算惩罚
```

当前图谱中 `SUITABLE_FOR.score` 已经给出用途匹配分，后续可以根据真实用户偏好进一步细化。

## 五、后续数据补充方向

1. 增加真实价格：京东、天猫、品牌官网价格，区分首发价、当前价和二手价。
2. 增加用途标签：风光、人像、视频、直播、街拍、体育、生态、商业棚拍。
3. 增加核心参数：有效像素、防抖档位、对焦点、续航、卡槽、屏幕形态、视频码率。
4. 增加镜头生态：卡口、镜头类型、焦段覆盖、价格、重量、防抖。
5. 增加用户画像：预算、已有镜头、拍摄经验、主要题材、便携要求。
6. 增加评测数据：媒体评分、用户评分、优点、缺点、发布日期。
7. 增加问答模板：把自然语言问题映射成 Cypher 查询。

## 六、答辩展示建议

10 分钟汇报可以展示三次查询：

1. 展示完整图谱：说明实体类型和关系类型。
2. 展示预算筛选：如“17000 元以内全画幅微单”。
3. 展示导购推荐：如“视频创作推荐哪些相机，为什么推荐”。

最后强调：本项目不只是相机参数表，而是能通过关系路径解释推荐理由的相机导购知识图谱。
