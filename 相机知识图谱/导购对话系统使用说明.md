# 相机购买建议对话系统使用说明

## 1. 功能

该系统把自然语言购机问题映射为 Cypher 查询，并连接 Neo4j Desktop 中已经创建好的相机知识图谱，返回推荐型号、品牌、类别、价格、推荐理由和实际查询语句。

支持示例：

- 新手小白应该买什么相机？
- 预算17000以内，想拍视频，推荐索尼相机
- 已有索尼镜头，应该买什么机身？
- Alpha 7 IV 为什么适合我？
- 想旅行随拍，预算12000以内

## 2. 启动方式

先确认 Neo4j Desktop 中的 `camera` 实例已经启动。

在命令行运行：

```powershell
cd F:\dongqiyan\知识图谱期末大作业\相机知识图谱
py camera_advisor_app.py
```

然后浏览器访问：

```text
http://127.0.0.1:5000
```

## 3. PyCharm 运行方式

1. 用 PyCharm 打开 `F:\dongqiyan\知识图谱期末大作业`。
2. 确认解释器为 `C:\Users\lenovo\AppData\Local\Programs\Python\Python312\python.exe`。
3. 打开 `相机知识图谱/camera_advisor_app.py`。
4. 点击运行。
5. 浏览器访问 `http://127.0.0.1:5000`。

## 4. Neo4j 连接配置

默认配置：

```text
URI: neo4j://127.0.0.1:7687
User: neo4j
Password: 12345678
Database: neo4j
```

网页左侧有 Neo4j 密码输入框。如果查询时提示密码错误，直接把输入框里的密码改成 Neo4j Desktop 当前数据库的真实密码，再重新提问。

也可以用环境变量覆盖：

```powershell
$env:NEO4J_PASSWORD="你的密码"
py camera_advisor_app.py
```

## 5. 答辩展示建议

展示流程：

1. 输入“新手小白应该买什么相机？”
2. 展示识别结果：用途为“入门学习”。

4. 展示下方生成的 Cypher，说明系统实现了“自然语言问题 -> 图谱查询 -> 导购建议”。
